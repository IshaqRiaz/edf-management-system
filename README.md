# EDF Record Management System

A modern, responsive **Employee Demand Form (EDF) & Material Request Management System** designed to simplify the creation, tracking, and management of office material requests. The system enables coordinators to manage requests efficiently with real-time tracking, Excel import, dashboard analytics, and an intuitive Kanban board.

---

## 📌 Features

### 📊 Dashboard

* Real-time operational overview
* Interactive statistics cards
* Category distribution charts
* Status matrix
* Live Delivery Watch
* Overdue monitoring
* Refresh dashboard functionality

### 📝 EDF Management

* Create, edit, view, and manage EDFs
* Track request lifecycle
* Requester selection
* Remarks & Notes
* Material summary
* Live countdown timer
* Mark EDF as Received or Completed

### 📥 Excel Import

* Paste Excel tables directly
* Import material data from Excel
* Automatic data extraction
* EDF number validation
* Preview before submission
* Preserve individual material rows
* Unit displayed before quantity

### 📋 Material Management

* Multiple material items per EDF
* Quantity and unit tracking
* Material summaries
* Category-wise organization

### 🔔 Notifications

* Real-time EDF notifications
* Overdue alerts
* Due within 24 hours alerts
* One-click navigation to the related EDF

### 📦 Kanban Board

* Drag-and-drop workflow
* Pending
* Received
* Completed
* Real-time status updates

### 📱 Responsive Design

* Desktop optimized
* Tablet support
* Mobile-friendly layout
* Responsive dashboard
* Adaptive forms and tables

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/IshaqRiaz/edf-recordmanagement-system.git
```

Navigate to the project folder:

```bash
cd edf-recordmanagement-system
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
